# PREGUNLAM
Trivia online referida a los departamentos de la Universidad Nacional de La Matanza

Pregunlam es una aplicación web de trivia interactiva que permite a los usuarios responder preguntas de diferentes categorías, competir con otros jugadores através del ranking global. Incluye un panel de administración completo con estadísticas, gestión de usuarios, visualización de reportes y sugerencias y un panel de editor para la gestión de preguntas, sugerencias y reportes.

-Este proyecto fue desarrollado como parte de la materia Programación Web 2, con el objetivo de aplicar conceptos de:

Desarrollo backend con Php
Arquitectura MVC
Diseño de bases de datos relacionales
Gestión de sesiones y autenticación
Visualización de datos con gráficos

-Características

Para Usuarios

Sistema de partidas: Juega respondiendo preguntas de múltiples categorías
Ranking: Compite con otros jugadores y sube en el ranking
Estadísticas personales: Visualiza tu rendimiento y progreso
Sistema de reportes: Reporta preguntas incorrectas o inapropiadas
Sugerencias: Propone nuevas preguntas para el juego

Para Administradores

Dashboard con métricas: KPIs y gráficos en tiempo real
Gestión de usuarios: Crear, editar, eliminar y gestionar roles
Visualización de reportes y sugerencias
Exportación a PDF: Genera reportes del sistema

Para Editores

Gestion de reportes: Analizar los reportes de las preguntas realizados por los usuarios y validarlos o rechazarlos.
Gestion de sugerencias: Analizar las preguntas sugeridas y validarlas o rechazarlas.
Gestion de preguntas: ABM de preguntas.
Gestion de categorias: ABM de categorias.

-Tecnologías
Backend

PHP 8.0+ - Lenguaje del servidor
MySQL 8.0+ - Base de datos relacional
Mustache.php - Motor de plantillas

Frontend

HTML5/CSS3/Tailwind - Estructura y estilos
JavaScript (Vanilla) - Interactividad
Chart.js - Gráficos y visualizaciones
html2canvas + jsPDF - Generación de PDFs
